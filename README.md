# 最長片道きっぷの旅

駅間の距離データをもとに、同じ駅を2回以上通らない最長経路を探索するPythonプログラムです。

## 1. プロジェクト概要

このプログラムでは、駅を頂点、駅と駅を結ぶ路線を辺とするグラフを作成し、最も距離が長くなる経路を探索します。

始点と終点は自由に選択でき、同じ駅を途中で重複して通らない経路を対象としています。

## 2. 主な機能

- 駅と駅の接続関係をグラフとして管理
- 駅間の距離を考慮した経路探索
- 同じ駅を2回以上通らない経路の探索
- 始点を変えながら最長経路を探索
- 最長経路に含まれる駅IDを順番に出力

## 3. 使用技術

| 項目 | 内容 |
|---|---|
| プログラミング言語 | Python 3 |
| 探索アルゴリズム | 深さ優先探索（DFS） |
| 入力 | 標準入力 |
| 出力 | 標準出力 |

## 4. 入力形式

駅間の接続情報を、1行につき1つずつ入力します。

各行は以下の形式です。

```text
駅ID,接続先の駅ID,距離
```

### 入力例

```text
1,2,5.2
2,3,3.4
3,4,6.1
1,4,2.8
```

### 各項目の説明

- 1列目：出発駅のID
- 2列目：接続先の駅ID
- 3列目：駅間の距離

駅間の接続は双方向として扱います。

## 5. 出力形式

最長経路に含まれる駅IDを、通過する順番に1行ずつ出力します。

### 出力例

```text
1
2
3
4
```

## 6. 実行方法

Python 3がインストールされている環境で実行できます。

入力データを `input.txt` に保存し、以下のコマンドを実行します。

```powershell
python main.py < input.txt
```


## 7. 探索アルゴリズム

深さ優先探索（DFS：Depth-First Search）を使用しています。

### 探索の流れ

1. 各駅を始点として探索を開始する。
2. 現在の駅から接続している駅を確認する。
3. まだ訪問していない駅があれば、その駅へ移動する。
4. 訪問済みの駅を管理し、同じ駅を再度通らないようにする。
5. 現在の経路の距離を計算する。
6. これまでに見つかった経路より長ければ、最長経路を更新する。
7. すべての探索が終了したら、最長経路を出力する。

## 8. テスト

ランダムに生成した300パターンのグラフを使用して、探索処理の動作を確認しました。

各パターンについて、実装した探索ロジックと枝刈りを行わない全探索の結果を比較しました。

- テストパターン数：300
- 結果が一致した数：300
- 不一致：0

※ 小規模なグラフを対象とした検証結果であり、すべての入力規模での動作や処理速度を保証するものではありません。

## 9. 工夫した点

- DFSを使用することで、さまざまな経路を探索できるようにした。
- 訪問済みの駅を集合で管理し、同じ駅を重複して通らないようにした。
- 現在の経路と最長経路を比較し、より長い経路が見つかった場合に更新するようにした。
- 始点を固定せず、すべての駅から探索することで最長経路を見つけられるようにした。
